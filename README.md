# MAISON D N A

Dépôt du thème Shopify de la boutique **Maison D N A**.

Ce dépôt est connecté à Shopify via l'intégration GitHub. Les fichiers du thème
(Liquid, CSS, JS, sections, templates…) sont synchronisés automatiquement entre
Shopify et ce dépôt.

## Branches

- `main` — thème de référence, synchronisé avec Shopify.
